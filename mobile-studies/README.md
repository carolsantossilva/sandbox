# Mobile Studies

iOS, Kotlin and mobile-adjacent backend exercises kept as the mobile engineering
foundation for this learning lab.

This track includes older studies and should also receive newer focused mobile
experiments, including mobile + AI ideas when they are still small enough to live
in the sandbox.

Current content:

- `ios`
- `kotlin`

These projects may require older local tooling and are not maintained as polished
portfolio projects.

Future examples:

- crash-log triage flows,
- release checklist helpers,
- app feedback classification,
- mobile UI prototypes backed by local mock data.
